# SecForge · 网安工具箱

SecForge 是一个本地运行的跨平台网络安全工具启动器与工具管理器。它的目标是为用户已有、且已获授权使用的安全工具提供统一的分类、搜索、配置、健康检查和启动入口。

> 当前处于项目骨架阶段：主窗口、数据模型和基础服务接口已经就绪；工具的新增、编辑、持久化接入和真实进程启动尚未实现。

## 合规说明

SecForge 仅可用于合法、已授权的安全测试、企业内部安全运维、CTF、靶场及安全学习研究。项目不会默认捆绑或自动执行任何第三方安全工具。

## 当前功能

- 可通过 PyQt6 启动无原生标题栏、圆角表面的桌面窗口，并提供自定义最小化、最大化/还原、关闭、拖动及 Windows 原生边缘/角落缩放交互；窗口最小尺寸为 950 × 600；
- 启动时使用 `sec-forge/assets/images/logo.png` 作为任务栏图标，并在系统托盘显示该图标；托盘菜单支持显示主窗口与退出程序，单击或双击图标可恢复主窗口；
- 自定义标题栏使用 `assets/images` 中的最小化、最大化和关闭图标；所有运行时素材路径由 `resources.py` 统一管理；
- 提供“全部工具、收藏、最近使用、分类、搜索”主界面布局：左侧导航栏固定为 220px 并紧贴窗口左、上、下边缘，左下角与窗口表面圆角一致；右侧工作区随窗口大小自适应，二者由 1px 竖直分隔线区分；
- 提供工具、工具启动配置和分类的数据模型；
- 支持 Python、Java 8 / 11、GUI、CLI、批处理、PowerShell 和网页等启动类型的配置表示；
- 提供仅进行配置和路径存在性检查的工具健康检查逻辑；
- 提供 JSON 格式配置存储接口；
- 预留跨平台启动器和 Windows 启动器接口。

## 运行要求

- Python 3.13 或更高版本；
- PyQt6 6.8 或更高版本。

项目依赖声明位于 [`pyproject.toml`](pyproject.toml)。安装好依赖后，在项目根目录运行：

```powershell
python sec-forge.py
```

## 项目结构

```text
sec-forge/
├── sec-forge.py       # 直接运行入口
├── sec-forge/         # 平铺的应用模块
│   ├── main.py         # 应用启动逻辑
│   ├── main_window.py  # 主窗口
│   ├── resources.py     # 应用静态资源路径定义
│   ├── assets/images/   # 任务栏、托盘和标题栏图标素材
│   ├── tool.py         # 工具与启动配置模型
│   ├── category.py     # 分类模型
│   ├── health_check.py # 配置与路径健康检查
│   ├── config_store.py # JSON 配置读写接口
│   ├── launcher.py     # 通用启动器抽象接口
│   ├── platform_base.py# 平台启动器抽象接口
│   └── windows.py      # Windows 启动器预留实现
├── tests/             # 基础模型与健康检查测试
└── pyproject.toml      # 项目元数据与依赖声明
```

根目录的 `sec-forge.py` 会自动把 `sec-forge` 目录加入模块搜索路径，因此无需安装项目包即可直接启动。

## 基础验证

可使用以下命令检查所有 Python 文件是否能通过编译：

```powershell
python -m compileall sec-forge tests
```

## 设计原则

- 优先在 Windows 10 / 11 上实现和验证，同时隔离平台差异；
- 默认不以管理员身份运行，不修改系统安全策略；
- 常规程序启动优先使用参数列表，避免把用户输入拼接为 Shell 命令；
- 健康检查只验证配置和路径，不主动运行扫描或攻击工具；
- 日志和配置导入功能实现时，默认避免保存密码、Token、Cookie、API Key 等敏感信息。
