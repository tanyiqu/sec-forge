# SecForge · 网安工具箱

SecForge 是一个本地运行的跨平台网络安全工具启动器与工具管理器。它的目标是为用户已有、且已获授权使用的安全工具提供统一的分类、搜索、配置、健康检查和启动入口。

> 当前已实现本地工具的新增和持久化；编辑、删除及真实进程启动仍处于规划阶段。

## 合规说明

SecForge 仅可用于合法、已授权的安全测试、企业内部安全运维、CTF、靶场及安全学习研究。项目不会默认捆绑或自动执行任何第三方安全工具。

## 当前功能

- 可通过 PyQt6 启动无原生标题栏、圆角表面的桌面窗口，并提供自定义最小化、最大化/还原、关闭、拖动及 Windows 原生边缘/角落缩放交互；窗口最小尺寸为 950 × 600；
- 启动时使用 `sec-forge/assets/images/logo.png` 作为任务栏图标，并在系统托盘显示该图标；托盘菜单支持显示主窗口、打开设置与退出程序，单击或双击图标可恢复主窗口；
- 自定义标题栏在 `SecForge` 左侧显示 `assets/images/logo.png`，并在“网安工具箱 by Tanyiqu”副标题右侧以纯文本形式每 5 秒显示一次当前进程的 CPU、内存占用及内存占比；最小化、最大化和关闭图标也来自该目录，所有运行时素材路径由 `resources.py` 统一管理；
- 提供“全部工具、收藏、最近使用、分类、搜索”主界面布局：左侧导航栏固定为 220px 并紧贴窗口左、上、下边缘，左下角与窗口表面圆角一致；“全部工具”“我的收藏”“最近使用”及各分类菜单分别使用 `all.png`、`star.png`、`recent.png` 和 `tools.png` 图标，菜单项之间不再显示横线分隔项；右侧工作区随窗口大小自适应，二者由 1px 竖直分隔线区分；“全部工具”、收藏及各分类菜单均显示对应工具数量；选择“全部工具”、收藏或任一分类时，右侧直接以固定 200 × 140 的工具信息卡片显示对应工具，并按 `weight` 从高到低、同权重按名称默认字符串顺序排列。卡片在名称左侧以 `ok.png` / `error.png` 显示本地工具路径状态，右侧提供可持久化的收藏按钮（`star-1.png` / `star-0.png`），右下角显示暂不执行实际操作的“运行”按钮；
- “添加工具”可用，并会打开与主界面风格一致、随内容自动适配高度的表单窗口；支持填写名称、描述、Python / Java 8 / Java 11 / GUI 应用 / 命令行 / 批处理 / PowerShell / 网页类型、文件路径（不限文件类型选择器）、网页 URL、已有分类、启动参数及 0–10 的权重（默认 0）。保存后立即追加到 `config/tools.json`，网页工具的 URL 写入 `url` 字段；
- “设置”会打开与主界面主题一致的固定 400 × 525 自定义标题栏模态窗口，提供关闭、常规/环境/关于选项卡以及重置、保存、取消按钮；常规页可设置“关闭窗口时最小化到系统托盘”，默认启用；环境页支持选择自定义 Python、Java 8 与 Java 11 路径，其中 Python 使用任意文件类型选择器，Java 8 / 11 使用文件夹选择器，保存后立即写入 `config/settings.json`；
- 主窗口关闭时，若“关闭窗口时最小化到系统托盘”已启用且系统托盘可用，则隐藏到托盘；关闭该选项或系统托盘不可用时，直接退出程序；
- 主窗口会在程序退出时将当前普通状态的 `width`、`height`、`x`、`y` 保存至 `config/settings.json`；下次启动时会在任一已连接显示器中原位恢复该尺寸和位置（支持副显示器及负坐标）。首次启动、配置缺失/无效或原显示器已断开导致窗口区域超出所有显示器可用范围时，窗口会回退到主显示器中央并写入对应配置；
- 提供工具、工具启动配置和分类的数据模型；
- 支持 Python、Java 8 / 11、GUI、CLI、批处理、PowerShell 和网页等启动类型的配置表示；
- 提供仅进行配置和路径存在性检查的工具健康检查逻辑；
- 程序启动时会在根目录创建 `config/`；其中 `settings.json` 保存系统设置（首次启动时会以 `sec-forge.py` 所在目录为基准生成 `env/python3/python.exe`、`env/Java_path/Java_8_win/bin`、`env/Java_path/Java_11_win/bin` 三个环境路径默认值），`categories.json` 以 `{"categories": ["分类名称", ...]}` 的字符串数组保存并驱动左侧分类菜单，数组从上到下的顺序即菜单展示顺序；旧版分类对象数组会在启动时自动迁移，`tools.json` 以 `name`、`category`、`type`、`description`、`path`、`params`、`url`、`weight`、`star` 字段组成的 JSON 数组保存工具配置，其中 `weight` 为 0–10 的整数，`star` 为收藏状态的布尔值；旧记录缺失或含无效值时会分别安全回退为 `0` 和 `false`，且不会覆盖已有配置；
- 预留跨平台启动器和 Windows 启动器接口。

## 运行要求

- Python 3.13 或更高版本；
- PyQt6 6.8 或更高版本。

项目依赖声明位于 [`pyproject.toml`](pyproject.toml)。安装好依赖后，在项目根目录运行：

```powershell
python sec-forge.py
```

## 项目结构

```text
sec-forge/
├── sec-forge.py       # 直接运行入口
├── sec-forge/         # 平铺的应用模块
│   ├── main.py         # 应用启动逻辑
│   ├── main_window.py  # 主窗口
│   ├── resource_monitor.py # 当前进程 CPU、内存占用采样
│   ├── resources.py     # 应用静态资源路径定义
│   ├── assets/images/   # 任务栏、托盘和标题栏图标素材
│   ├── tool.py         # 工具与启动配置模型
│   ├── category.py     # 分类模型
│   ├── health_check.py # 配置与路径健康检查
│   ├── config_store.py # JSON 配置读写接口
│   ├── launcher.py     # 通用启动器抽象接口
│   ├── platform_base.py# 平台启动器抽象接口
│   └── windows.py      # Windows 启动器预留实现
├── tests/             # 基础模型与健康检查测试
├── config/            # 启动时自动创建的本地 JSON 配置目录
├── env/               # 工具运行时环境目录，不纳入项目源码检索
└── pyproject.toml      # 项目元数据与依赖声明
```

根目录的 `sec-forge.py` 会自动把 `sec-forge` 目录加入模块搜索路径，因此无需安装项目包即可直接启动。

## 基础验证

可使用以下命令检查所有 Python 文件是否能通过编译：

```powershell
python -m compileall sec-forge tests
```

## 设计原则

- 优先在 Windows 10 / 11 上实现和验证，同时隔离平台差异；
- 默认不以管理员身份运行，不修改系统安全策略；
- 常规程序启动优先使用参数列表，避免把用户输入拼接为 Shell 命令；
- 健康检查只验证配置和路径，不主动运行扫描或攻击工具；
- 日志和配置导入功能实现时，默认避免保存密码、Token、Cookie、API Key 等敏感信息。
